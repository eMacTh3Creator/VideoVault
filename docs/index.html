Built like a download manager, not a URL textbox.

VideoVault wraps yt-dlp in a native Mac workflow with queue persistence, detail views, smarter fallbacks, and settings that matter for real-world downloads.

Batch

Queue one link or a hundred.

Paste unlimited URLs, keep them in a persistent queue, and let VideoVault process them in the background without freezing the app.

Fallbacks

Resolution requests fail gracefully.

720p, 1080p, 1440p, 4K, and best-available downloads automatically fall back when an exact format is not exposed by the source.

YouTube

Handles the messy parts.

Browser cookies, realistic user-agent headers, extractor arguments, and ffmpeg integration help VideoVault survive common YouTube edge cases.

Metadata

Save more than just the file.

Optionally embed thumbnails, titles, and uploader metadata into completed downloads when the format supports it.

Organization

Keep files sorted by source.

Downloads can be grouped automatically into per-site folders like youtube, vimeo, or reddit.

Native

Designed for macOS first.

SwiftUI split-view layout, notifications, onboarding, settings sheets, and Finder-friendly actions make it feel like a real desktop app.

Install in a few minutes.

The app is simple to get running: download the release, clear the first-launch warning once, then let onboarding detect or install its helper tools.

1

Download

Open the latest GitHub Release and download the current macOS zip for VideoVault.

2

Move

Unzip the archive and drag VideoVault.app into your /Applications folder.

3

Open once

Because the app is unsigned, first launch may require right-clicking the app and choosing Open.

4

Finish onboarding

Let VideoVault detect or install yt-dlp and ffmpeg, then start queueing links.

Dependencies: VideoVault relies on yt-dlp for extraction and ffmpeg for stream merging and MP3 conversion. The app is designed to help users install both during first launch, so Homebrew is convenient but not required.

Windows port in progress

A native Windows scaffold now lives in the repository as a C# / .NET 8 / WPF solution. The Mac app is still the primary release, but the repo now includes an early Windows project structure for future development.
