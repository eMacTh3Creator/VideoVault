Built like a download manager, not a URL textbox.

VideoVault wraps yt-dlp in native Mac and Windows workflows with queue persistence, detail views, supported recovery paths, and settings that matter for real-world downloads.

Batch

Queue one link or a hundred.

Paste unlimited URLs, keep them in a persistent queue, and let VideoVault process them in the background without freezing the app.

Fallbacks

Resolution requests fail gracefully.

720p, 1080p, 1440p, 4K, and best-available downloads automatically fall back when an exact format is not exposed by the source.

YouTube

Handles the messy parts.

Automatic verified yt-dlp updates, JavaScript runtime setup, browser cookies, and ffmpeg integration keep the extraction tools ready for changing sites.

Duplicates

Keep one good copy.

Skip indexed repeat downloads and find exact-content duplicates throughout your destination folder. Safely move selected extra copies to Trash or the Windows Recycle Bin.

Organization

Keep files sorted by source.

Downloads can be grouped automatically into per-site folders like youtube, vimeo, or reddit.

Native

At home on either desktop.

A Home button and live Mac menu bar or Windows tray counts keep you in control. Quick paste best video or original-quality audio without bringing the window forward.

Install in a few minutes.

Choose your platform, install the app, then let VideoVault detect or install its helper tools. Internet access is needed for first-run tool setup.

1

Download

Choose the Mac DMG, Windows x64 installer, or Windows ARM64 installer above.

2

Install

On Mac, drag VideoVault.app to Applications. On Windows, run the installer, or extract the portable ZIP into its own folder.

3

Open once

Launch VideoVault. Mac builds are not notarized and Windows previews are unsigned, so your operating system may show a first-launch security warning.

4

Finish onboarding

Let VideoVault detect or install yt-dlp and ffmpeg, then start queueing links.

Dependencies: VideoVault relies on yt-dlp for extraction and ffmpeg for stream merging and MP3 conversion. The app is designed to help users install both during first launch, so Homebrew is convenient but not required.
