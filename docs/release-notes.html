VideoVault 1.5.1 - Mac multi-selection

  • Command-A selects all shown downloads, respecting search and status filters. Command-click toggles individual items; Shift-click selects a range.
  • Right-click a selected row for batch Retry, Force Retry, Cancel, Copy URLs, Show in Finder, and Remove. The detail panel shows batch controls and eligible-item counts.
  • Selection stays attached to stable download IDs while progress and metadata change. Hidden and removed rows are excluded.
  • Retry affects failed/cancelled items only; Cancel affects active/queued items only. Bulk queue changes are batched to keep processing responsive.
  • Command-C copies URLs. Delete removes list entries; multiple removals require confirmation. Saved files are not deleted.

All 39 Mac tests passed with no failures or skips, including six new multi-selection tests and a 2,000-item batch. The universal Intel/Apple Silicon app and DMG are Developer ID-signed and Apple-notarized with stapled tickets. Interactive UI testing remains outstanding because the running app was not opened or restarted.

Mac v1.5 users receive this update through the existing signed update channel. Users on v1.4 or earlier need one manual installation of v1.5.1. Windows remains at v1.5.0; its existing unsigned installers and updater assets are retained unchanged. This release adds multi-selection to Mac only.

Earlier: VideoVault 1.5

  • Automatically use Force Retry after recoverable postprocessing failures, including FFmpeg's "Error opening output files: Invalid argument" diagnostic.
  • Choose 1-10 automatic Force Retry attempts in Settings; the default is 3 extra attempts per download.
  • Forced attempts skip optional thumbnail and metadata work while keeping the chosen quality, duplicate protection, and access restrictions.
  • Retries use short, increasing delays, stop at the configured limit, and can be cancelled during the delay. Turning automatic retries off disables them.
  • Try yt-dlp recovery before unsupported Streamlink fallbacks for postprocessing errors. Clarify that a missing Streamlink plugin is a backup limitation, not a verdict on the source.
  • Matching recovery options are included in Windows x64 and ARM64 builds.

One manual Mac installation is required: The previous publisher key could not be recovered. Install 1.5 manually once to use the new signed update channel. Older feeds are preserved; private publisher keys are never included in the app.

The universal Mac app and disk image are Developer ID-signed and Apple-notarized, with stapled tickets. Gatekeeper and ticket validation passed, including the app extracted from the ZIP and the app inside the disk image. Use the new -notarized downloads; the original downloads are retained for cached update feeds. Windows builds remain unsigned previews.
