VideoVault 1.4

  • New drag-to-Applications installer for Intel and Apple Silicon.
  • Automatic signed update checks start on first launch. No scripts, signing keys, or Terminal setup are needed by users.
  • Intel setup uses the built-in yt-dlp and ffmpeg installers; Homebrew remains optional on Apple Silicon.
  • Installation failures display their error beside the relevant button.

Open the disk image, drag VideoVault to Applications, then launch it from Applications. Versions 1.3.x require this one manual installation to join the new update channel.

The app is ad-hoc signed and is not Apple-notarized; macOS may require approval in Privacy & Security for first launch.
