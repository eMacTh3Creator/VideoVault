VideoVault 1.3

  • Automatic yt-dlp release checks and checksum-verified updates, with YouTube runtime setup.
  • Signed automatic app updates, installation, and relaunch through Sparkle.
  • Skip previously downloaded files in the destination folder, including duplicates with different filenames.
  • Duplicate Finder compares file contents and lets you move selected copies to Trash while keeping an original.
  • Reliable cancellation, fetch timeouts, bounded retries, accurate output tracking, and Streamlink or direct-media ffmpeg fallback.
  • Home button returns to the native Add URLs screen.
  • Menu bar icon shows active, queued, and failed counts. Quick Paste starts best-quality video or original-quality audio downloads in the background.

Streamlink is optional and supports a subset of sites. Install it in Settings. Site access restrictions retain their original error and support instructions.

Users of 1.2 must install this release once to enable automatic updates for future versions.
