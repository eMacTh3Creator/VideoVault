VideoVault 1.3.1

  • Fix menu bar freezes while downloading and adding more videos.
  • Independent background download workers, asynchronous queue saves, and bounded progress updates keep the UI responsive.
  • Live active, queued, and failed counts update without rebuilding an open menu.
  • Quick-paste commands read the clipboard after the menu closes, not while it is opening.
  • Cancel one download without interrupting the others. Shutdown waits asynchronously for workers and pending saves.
  • Inherited subprocess output pipes can no longer cause an indefinite wait after the downloader exits.

Universal Intel and Apple Silicon build for macOS 13 or later. Existing v1.3 users can update through Sparkle; v1.2 users must install manually once.

This patch retains v1.3 tool updates, duplicate protection, Home navigation, and independent fallback downloads. Site access restrictions are not bypassed.
