VideoVault 1.4

  • New drag-to-Applications installer for Intel and Apple Silicon.
  • Automatic signed update checks start on first launch. No scripts, signing keys, or Terminal setup are needed by users.
  • Intel setup uses the built-in yt-dlp and ffmpeg installers; Homebrew remains optional on Apple Silicon.
  • Installation failures display their error beside the relevant button.

Open the disk image, drag VideoVault to Applications, then launch it from Applications. Versions 1.3.x require this one manual installation to join the new update channel.

The app is ad-hoc signed and is not Apple-notarized; macOS may require approval in Privacy & Security for first launch.

Windows 1.4.0 development preview

  • Native C# / .NET 10 / WPF application, with self-contained x64 and ARM64 installers and portable ZIPs alongside the Mac release.
  • Independent download processes, bounded metadata timeouts, responsive progress updates, and persistent queues.
  • Verified first-run yt-dlp, FFmpeg, Deno, and Streamlink setup; automatic yt-dlp checks on launch.
  • Destination duplicate protection, content-based duplicate finder, and safe Recycle Bin handling.
  • Home navigation and system-tray active/queued/failed counts, quick-paste best video/audio, and queue controls.
  • Corrected Settings labels and buttons, wrapping options, small-screen scrolling, and saved-quality selection.
  • Force Retry and supported independent recovery paths preserve DRM, login, and access restrictions.

Unsigned development builds: Windows SmartScreen may show a warning. Windows 11 ARM64 regression and local-media integration tests passed 42 checks. Native x64 hardware and installed old-to-new app-update validation remain pending. Portable copies do not install app updates.
